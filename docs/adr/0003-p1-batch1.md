# ADR-0003：P1 第一批——runtime.fx / 钥匙串 / bayze models / per-run max_chars

状态：已接受（2026-11-05）
依据：实施基线规范 v0.4.1 §5 P1 + dogfood 实测发现

## 决策

| # | 功能 | 设计 |
|---|---|---|
| D1 | **runtime.fx** | 顶层 `runtime.fx` 配置：`{ currency: CNY, rate_to_usd: 0.14, updated_at: "2026-11-05" }`。BudgetGuard 的 priceBook 在遇到非 USD 定价时查 fx 表换算，而非 fail-closed。需同时配置 `rate_to_usd` 和 `updated_at`（提醒用户汇率有时效性） |
| D2 | **macOS 钥匙串** | CredentialStore 新增 `keychain:` 前缀引用（如 `api_key_ref: "keychain:BAYZE_DEEPSEEK_API_KEY"`），通过 `security find-generic-password -s bayze -w <name>` 读取。写入用 `security add-generic-password`。仅 macOS 支持，其他平台 fallback 到 env 并警告 |
| D3 | **`bayze models` 命令** | CLI 子命令，调用 Bayze API `GET /v1/models` 列出可用模型 id，帮助用户配置。需 `BAYZE_API_KEY` 环境变量 |
| D4 | **per-run max_chars** | `user_overrides` 扩展 `max_chars` 字段（收紧-only）：`run_workflow` 调用时传入，引擎将该值注入对应步骤的确定性检查 |

## 不做的事

- localhost HTTP API（需独立安全评审 + ADR）
- 图形界面（工作量大，非核心）
- 多模型并行比较（需新策略引擎扩展）
